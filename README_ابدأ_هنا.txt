المروة - نسخة مراجعة وإصلاح أولية - 14 أكتوبر 2026

1) احتفظ بنسخة احتياطية من Supabase قبل أي شيء. لا ترفع api/db.json أو أي ملف SQL يحوي بيانات عملاء لمستودع عام.
2) افتح Supabase > SQL Editor ونفّذ sql/marwa_mutate_resource.sql في نفس قاعدة البيانات التي تحوي app_data (id=1) و admin_users.
3) متغيرات Vercel server: SUPABASE_URL / SUPABASE_SERVICE_KEY. ومتغيرات web build: VITE_SUPABASE_URL / VITE_SUPABASE_ANON_KEY. ممنوع وضع مفتاح service role داخل متغير VITE_.
4) اضبط Vercel Root Directory حسب إعداد المشروع الحالي. تشغيل الواجهة محليًا: cd web && npm install && npm run dev.
5) إصلاحات: CRUD إدارة المدير، ظهور كتالوج المنتجات العام، أسماء subcategories، شاشة إحصائيات مالية، ألوان فاتحة، زر واتساب يدوي، واحتفاظ نسخ PDF المصححة.
6) مهم: تسجيل/دخول العميل وإرسال أوردر العميل لا يزالان بحاجة لبناء مصادقة مستقلة مؤمنة على Supabase Auth؛ API يرفض كتابة المستخدم غير المدير عمدًا. لا تعتمد النسخة للإنتاج في تدفق العملاء بعد.
7) بوت واتساب التلقائي الحقيقي لم يربط بعد؛ زر واتساب يفتح محادثة يدوية فقط. يلزم WhatsApp Business Platform و webhooks ومراجعة الصلاحيات والخصوصية.
8) رفع ملفات PDF كـ base64 في JSON حل قديم ومحدود؛ يلزم ترحيل المرفقات إلى Supabase Storage قبل التشغيل الكبير. الحد المؤقت للتصحيح 1.9MB.
9) الإصلاحات البرمجية غير مختبرة على Supabase الحقيقي بدون مفاتيح المشروع/بيانات الاتصال.
