# المروة — نسخة فحص V3 (غير جاهزة للنشر العام)

## ما تم
- تحسين معالجة أخطاء الواجهة في اتصالات API لتجنب تنبيهات نجاح وهمية.
- المحافظة على ملفات API وSQL السابقة، والتصميم وPDF وزر واتساب.
- إضافة مثال إعدادات البيئة للواجهة دون إدخال أي مفتاح حقيقي.

## مهم قبل الإنتاج
1. تسجيل العملاء وإرسال الأوردرات **متوقفان في هذه النسخة** ولم يتم حل نظام المصادقة الآمن بعد.
2. يجب تنفيذ API عبر Vercel مع متغيرات الخادم SUPABASE_URL وSUPABASE_SERVICE_KEY محفوظة في إعدادات Vercel فقط. لا توضع هذه المفاتيح في React.
3. دالة SQL في sql/marwa_mutate_resource.sql تحتاج مراجعة وتجربة على نسخة قاعدة بيانات منفصلة قبل التنفيذ.
4. لا تنشر على main ولا تستبدل الموقع الحالي قبل اختبار بناء الواجهة وأذونات العملاء والفواتير وحفظ الملفات.
5. بوت واتساب الفعلي غير موصول؛ الموجود في النظام وسائل تواصل/مراجعة مبدئية فقط.
6. لا يتم ضمان اختبار npm build في بيئة الإنشاء الحالية لأن تثبيت الاعتمادات تعذر.

## خطة الاختبار
- التأكد من GET /api/categories يعيد JSON.
- تجربة تسجيل المدير وإجراء إضافة تصنيف تجريبي على بيئة منفصلة.
- إنشاء نظام Auth خاص بالعملاء مع تحقق الأسعار داخل الخادم قبل تفعيل الطلبات.
- استكمال واتساب Business webhook واختبارات استقبال الرسائل.
